# Project-Specific Standards

## Nostr Integration
- Follow Nostr NIP specifications when applicable
- Use proper event signing and validation
- Handle relay connections gracefully

## Code Organization
- Separate client and server concerns
- Avoid TypeScript if possible. Use proper TypeScript types if using TypeScript
- Implement proper error handling
- Add logging for debugging

## Testing
- Write unit tests for core functionality
- Test Nostr event handling
- Mock external dependencies

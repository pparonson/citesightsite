# Penitin Project Guidelines

## Project Context
This is a Node.js application with Nostr protocol integration for decentralized communication.

## Technology Stack
- Node.js 18+ LTS
- npm package manager
- Avoid TypeScript when possible
- Nostr protocol components

## Project Structure
- Client application in `client/`
- Tests in `tests/` or `test/`
- Documentation in `docs/`

## Key Conventions
- Use conventional commit messages
- Separate client and server concerns
- Implement proper error handling
- Add logging for debugging

Detailed coding standards, Nostr integration guidelines, and testing strategies are maintained in `docs/project-standards.md`.
